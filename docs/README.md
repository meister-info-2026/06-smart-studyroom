# docs 안내 — 어떤 문서를 언제 보나요

이 저장소(`study` 브랜치)는 **1차 개발(FastAPI 백엔드, MariaDB 스키마/시드, Next.js 실시간 대시보드, ONNX 기반 비전 클라이언트)이 이미 자립 동작 가능한 형태로 완성**되어 있습니다.

학생들은 이 코드를 클론하여 **2차 개발(라즈베리파이 5 실제 하드웨어 배선 및 연동, 비전 기능 확장, 클라우드 배포)**을 이어가게 됩니다. 아래 목차에 따라 필요한 문서를 확인하세요.

## 역할별 권장 학습 순서

| 역할 | 1단계 (환경 구축 및 검증) | 2단계 (2차 개발 본작업) | 비고 |
|---|---|---|---|
| **팀 전원** | 01, 02 매뉴얼 (로컬 구동 확인) | 03 AI 연동 가이드 | 3개 터미널로 백엔드/프론트/비전 연동 확인 |
| **라즈베리파이** | 01, 02 매뉴얼 | **부록B 슬라이드 → 부록A 인터페이스 가이드 → 03 가이드** | 실제 핀 배선 및 `pi/main.py` 데몬 구현 |
| **백엔드·DB** | 01, 02 매뉴얼 | **03 가이드 → 부록A 인터페이스 가이드** | 하드웨어 프로바이더 전환, API/DB 확장 |
| **프론트엔드** | 01, 02 매뉴얼 | **03 가이드 (6장 디바이스 카드 확장)** | 실시간 대시보드 UI 개선 및 액추에이터 제어 |
| **영상인식** | 01, 02 매뉴얼 | **03 가이드 (비전 파이프라인 및 트리거)** | 캘리브레이션, 신규 자세 감지 로직 고도화 |
