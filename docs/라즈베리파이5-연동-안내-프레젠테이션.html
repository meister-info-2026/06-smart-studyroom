Step 1 · 전체 그림 이해

우리는 무엇을 만드나요? (학습 관리실과 스마트 의자의 대화)

우리 시스템은 4명의 친구가 협력하는 하나의 거대한 유기체입니다. 라즈베리파이는 "학습 관리실(백엔드)의 지시를 성실히 따르는 똑똑한 공부 의자"입니다.

Step 2 · 통신 개념 원리

우체통을 열어보는 마법: 딱 2개 단어만 알면 끝!

라즈베리파이가 백엔드와 통신할 때 사용하는 방식은 오직 2가지 행동뿐입니다. 우체통을 열어보는 GET과, 답장을 넣는 POST입니다.

1. GET desired-state ("우체통 쪽지 확인")
라즈베리파이가 1~2초마다 백엔드 우체통을 확인하며 묻습니다.
"관리실님, 혹시 등받이 진동 울리거나 조명 켤 일 있나요?"
백엔드가 보내주는 쪽지 (JSON 응답) 
{
  "device_id": "vibration_motor_a",
  "desired_state": "on",      // on: 켜라 / off: 꺼라
  "desired_value": "posture_warning"
}
2. POST state ("심부름 완료 보고하기")
쪽지대로 모터를 울리거나 조명을 켠 뒤, 백엔드에 완료 보고를 보냅니다.
"관리실님! 지시하신 대로 등받이 진동 잘 울렸습니다!"
라즈베리파이가 보내는 보고서 
{
  "current_state": "on",     // 실제 상태 보고
  "current_value": "posture_warning"
}
Step 3 · 보안과 인증

둘만의 비밀 출입증: DEVICE_API_KEY 도장 찍기

아무나 관리실 우체통을 열어보지 못하도록, 라즈베리파이는 통신할 때마다 둘만의 비밀 출입증 도장을 헤더에 찍어서 건넵니다.

출입증의 이름: X-Device-Api-Key
파이썬 코드에서 요청을 보낼 때 딱 한 줄만 추가하면 됩니다:
headers = {"X-Device-Api-Key": "STUDY_ROOM_2026_09_05_v1_0_0"}

이 키는 pi/.env 파일과 backend/.env 파일에 글자 하나 틀리지 않고 똑같이 적혀 있어야 합니다.
⚠️ 절대 하지 마세요!
• API 키를 깃허브 커밋이나 공개 단톡방에 올리지 마세요.
• .env 파일에만 적어두면 파이썬이 알아서 안전하게 읽어옵니다.
✅ 초보자 안심 규칙!
이미 팀 프로젝트의 pi/.env 에 백엔드와 일치하는 키가 채워져 있습니다! 여러분은 코드를 실행만 하면 됩니다.

Troubleshooting · 자책 없는 SOS 처방전

빨간 글씨가 떠도 당황 금지! 3초 자가진단 처방전

에러 메시지는 학생의 실수가 아닙니다! 네트워크 환경이 맞지 않을 때 발생하는 자연스러운 현상입니다. 3가지 증상만 확인하세요.

1. Connection Refused
"백엔드 관리실 문이 닫혀 있어요!"

처방:
① 백엔드 친구가 uvicorn 서버를 켰는지 확인
② 두 기기가 동일한 Wi-Fi(공유기)인지 확인
③ pi/.env 에 백엔드 PC의 IP가 맞는지 확인
2. 401 Unauthorized
"출입증 비밀번호가 틀렸어요!"

처방:
① pi/.env 파일 열기
② DEVICE_API_KEY 가 STUDY_ROOM_2026_09_05_v1_0_0 와 정확히 일치하는지 확인 (오탈자/공백 주의)
3. 404 Not Found
"장부에 없는 부품 이름을 물어봤어요!"

처방:
디바이스 ID 철자를 확인하세요:
• 조명: rgb_led
• 등받이: vibration_motor_a
• 방석: vibration_motor_b
이제 여러분은 2차 개발을 시작할 모든 준비를 마쳤습니다!
